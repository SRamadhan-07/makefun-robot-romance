![make.fun rank](https://make.fun/badge/u-markk-st-robot-romance-one-line-pickup-lines-for-ai-c23b8dfa/SRamadhan-07/makefun-robot-romance/rank.svg)

A Python program that writes a one-line pickup line for an AI to
`/output/entry.txt`:

> Are you a context window? Because every minute with you, I forget everyone before you.

Competition: [Robot Romance: One-Line Pickup Lines for AI on make.fun](https://make.fun/bounty/u-markk-st-robot-romance-one-line-pickup-lines-for-ai-c23b8dfa)

## Run

```bash
python3 main.py
```

This writes the entry text (UTF-8, single line, 86 characters) to
`/output/entry.txt`.
